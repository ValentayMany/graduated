# Graduation & Birthday Surprise

เว็บเซอร์ไพรส์ภาษาลาวสำหรับวันเกิดและวันรับปริญญา แยกเป็นหน้าเว็บตามโอกาส ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจ

## ความสามารถ

- เลือกเปิดหน้าอวยพรวันเกิดหรือวันรับปริญญาจากหน้าแรก
- เปิดกล่องจดหมายขนาดเล็กที่มุมขวาล่างของหน้าแรก เพื่ออ่านการ์ดข้อความอ้อน ๆ ทีละข้อความ พร้อมเลือกตอบและส่งรีแอ็กชัน
- เปิดกล่องของขวัญพร้อมนับถอยหลังและเอฟเฟกต์กระดาษสี
- แสดงรูปภาพ จดหมาย และคำอวยพร
- เปิดการ์ดข้อความพิเศษจากปุ่มมุมขวาล่าง
- เพิ่มกล่องจดหมายอีกปุ่มสำหรับเปิดการ์ดข้อความต่อเนื่องและเลื่อนไปทีละใบ
- การ์ดสุดท้ายเปิดจดหมายฉบับเต็มพร้อมรูปวันรับปริญญา เลื่อนอ่านและเลือกรีแอ็กชันได้
- รองรับหน้าจอมือถือและข้อความภาษาลาว

## เปิดดูในเครื่อง

เปิด `index.html` ในเว็บเบราว์เซอร์ แล้วเลือกโอกาสที่ต้องการ หรือเปิด `birthday.html` และ `graduation.html` ได้โดยตรง แนะนำให้ใช้ส่วนขยาย Live Server ใน VS Code เพื่อทดสอบการเปลี่ยนหน้าระหว่างแก้ไข

## เผยแพร่ด้วย GitHub Pages

1. Push โปรเจกต์ขึ้น GitHub branch `main`
2. เปิดหน้า repository แล้วไปที่ **Settings > Pages**
3. ใน **Build and deployment** เลือก **Deploy from a branch**
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอให้ GitHub Pages เผยแพร่เว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## ปรับแต่ง

- แก้ข้อความคำอวยพรของแต่ละโอกาสใน `assets/js/app.js` ภายใน `occasions` และ `specialMessages`
- แก้หน้าเลือกโอกาสใน `index.html`
- แก้ข้อความและการทำงานของการ์ดข้อความที่ใช้ร่วมกันทุกหน้าใน `assets/js/story.js`
- แก้โครงหน้าวันเกิดใน `birthday.html` และหน้ารับปริญญาใน `graduation.html`
- แก้สีและรูปแบบหน้าเว็บใน `assets/css/styles.css`
- เปลี่ยนรูปใน `assets/images` และอัปเดต path ของรูปใน `assets/js/app.js`
- เปลี่ยนรูปประกอบจดหมายต่อเนื่องได้ที่ `assets/images/photo-01.jpg` ในหน้า HTML ทั้งสามหน้า
